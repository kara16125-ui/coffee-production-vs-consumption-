# coffee-production-vs-consumption-

Compares coffee production and domestic consumption by country (1990-2020)
using Python, Pandas (merge, groupby) and Matplotlib.

Key findings:
- Brazil has the largest surplus (production minus consumption), followed by Viet Nam and Colombia.
- Philippines, Venezuela and Cuba consume more than they produce.
- Philippines consumption is about 315% of its production (as reported in the dataset).

Tools: Python, Pandas, Matplotlib
Data source: Kaggle (Coffee dataset)
